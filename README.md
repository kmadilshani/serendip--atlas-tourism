Serendip Atlas 🌴

A modern and responsive tourism website designed to showcase the beauty, culture, destinations, and travel experiences of Sri Lanka.

✨ Features

- 🌴 Explore Sri Lankan destinations
- 🏝️ Tourist attractions
- 🗺️ Travel experiences
- 📸 High-quality destination images
- 🧳 Tourism packages
- 📱 Responsive design
- 🌐 Modern and user-friendly UI
- 📞 Contact and inquiry section

🛠️ Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- HTML5
- CSS3
- JavaScript

🎯 Project Goal

The goal of Serendip Atlas is to provide travelers with an attractive and easy-to-use digital platform for discovering Sri Lanka and planning memorable travel experiences.

🚀 Getting Started

Install dependencies:

npm install

Run the development server:

npm run dev

Then open:

http://localhost:8443
